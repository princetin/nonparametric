# nonparametric

# Олимпиадный опыт и пространственная интуиция: одно ли это и то же?

Исследовательский проект по непараметрической статистике. Мы проверяем,
связан ли успех в задачах на пространственное мышление с олимпиадным опытом
школьников, и какие ещё факторы (пол, самооценка, школьные оценки, спорт,
шахматы, тип увлечений) на него влияют.

**Авторы:** Ильин А., Киселёв И., Верещак Т.
**Организация:** НИУ ВШЭ, факультет математики · Май 2026

---

## Краткое содержание

Школьникам 7-го класса (N = 43) давали батарею стереометрических задач
(объём «нарезанной» головы, форма крышки люка, склеивание многогранников,
объём жидкости в бокале-тетраэдре). Ответы переводились в ординальную шкалу.
Так как данные порядковые, скошенные и не подчиняются нормальному
распределению, для анализа использованы **ранговые (непараметрические)
методы**: корреляции Спирмена и Кендалла, критерий Манна — Уитни и критерий
Краскела — Уоллиса.

**Главный результат:** из всех проверенных факторов значимыми оказались только
два — олимпиадный рейтинг (умеренная связь, ρ ≈ 0.34) и интерес к
математике/геометрии как любимому предмету. Пол, самооценка, школьная
успеваемость, спорт и тип увлечений значимой связи с результатом теста не
показали. Пространственное мышление выглядит как отдельная способность, не
сводящаяся к олимпиадной подготовке и не измеряемая школьными оценками.

## Методы

Все скрипты работают по одной схеме: загружают таблицу (CSV или Excel),
считают непараметрический критерий, печатают итог в консоль и рисуют график.
Параметры (путь к файлу, имена столбцов, уровень значимости) задаются в блоке
`НАСТРОЙКИ` в начале каждого файла.

### `correlation_kendall_spearman.py`
Ранговые корреляции **Спирмена (ρ)** и **Кендалла (τ)** между выбранными
числовыми столбцами, с p-значениями для каждой пары и двумя тепловыми картами.
Подходят для монотонной (необязательно линейной) связи на ненормальных данных.

### `mann_whitney_test.py`
Критерий **Манна — Уитни (U)** — непараметрический аналог t-критерия для двух
независимых групп. Поддерживает два формата данных: «long» (столбец значений +
столбец групп) и «wide» (по столбцу на группу). Считает также размер эффекта
(ранговая бисериальная корреляция).

### `kruskal_wallis_test.py`
Критерий **Краскела — Уоллиса (H)** — аналог однофакторного ANOVA для трёх и
более групп. При значимом результате запускает пост-хок тест Данна с поправкой
на множественность (нужен пакет `scikit-posthocs`).

## Результаты

| Что проверяли | Метод | Статистика | p-value | Вывод |
|---|---|---|---|---|
| Олимп. рейтинг ↔ балл теста | Спирмен | ρ = 0.34 | 0.025 | **значимо** |
| Олимп. рейтинг ↔ балл теста | Кендалл | τ = 0.30 | 0.023 | **значимо** |
| Любимый предмет (мат/геом) vs остальные | Манн — Уитни | U = 289.5 | 0.028 | **значимо** |
| Пол (м vs ж) | Манн — Уитни | U = 192.0 | 0.64 | не значимо |
| Самооценка ↔ балл теста | Кендалл | ρ = 0.23 | 0.13 | не значимо |
| Школьная оценка ↔ балл теста | Спирмен | ρ = −0.166 | 0.558 | не значимо |
| Шахматы (да vs нет) | Манн — Уитни | U = 123.5 | 0.247 | не значимо |
| Спорт (да vs нет) | Манн — Уитни | U = 170.0 | 0.212 | не значимо |
| Тип увлечений (≥3 групп) | Краскел — Уоллис | H = 1.786 | 0.775 | не значимо |

Связь олимпиадного опыта с тестом существует, но **умеренная**: ρ = 0.34
далеко от 1.0, бо́льшая часть разброса результатов олимпиадным рейтингом не
объясняется.

## Выводы

- **Олимпиады помогают, но не гарантируют** — связь умеренная; пространственная
  интуиция не сводится к олимпиадной подготовке.
- **Интерес к математике/геометрии** связан с лучшим результатом (но возможен
  конфаундинг с олимпиадным опытом).
- **Пол не имеет значения** — стереотип о мужском преимуществе на наших данных
  не подтвердился.
- **Самооценка не работает** — дети плохо оценивают собственные способности к
  нестандартным задачам.
- **Школьные оценки ничего не говорят** о пространственном мышлении — это
  отдельная способность, не измеряемая стандартной системой оценивания.

## Как запустить

### Требования
- Python 3.9+
- `numpy`, `pandas`, `scipy`, `matplotlib`, `seaborn`
- `openpyxl` — для чтения `.xlsx`
- `scikit-posthocs` — опционально, для пост-хок теста Данна

```bash
pip install numpy pandas scipy matplotlib seaborn openpyxl scikit-posthocs
```

### Настройка
В каждом скрипте в блоке `НАСТРОЙКИ` укажите:
- `DATA_PATH` — путь к файлу с данными (`.csv` или `.xlsx`);
- имена столбцов (`COLUMNS`, `VALUE_COLUMN`, `GROUP_COLUMN` и т. д.) —
  под реальные заголовки вашей таблицы;
- при необходимости `MODE` (`"long"` / `"wide"`) в `mann_whitney_test.py`.

### Запуск
```bash
python correlation_kendall_spearman.py
python mann_whitney_test.py
python kruskal_wallis_test.py
```
Каждый скрипт печатает результаты в консоль и сохраняет график рядом со
скриптом (имя задаётся в `FIGURE_PATH`).

## Ограничения

- **Малый объём выборки** (N = 43) — достаточно для разведочного анализа, но
  мало для окончательных выводов; в подгруппах (шахматы n = 5) мощность тестов
  низкая.
- **Дисбаланс по полу** (32 М / 11 Ж) снижает мощность гендерного сравнения.
- **Бинарные задачи** — три из четырёх задач требовали ответа «да/нет», что не
  позволяло оценить ход мысли; нужна полностью ординальная шкала 0–4.
- **Возможный конфаундинг** между интересом к математике и олимпиадным опытом —
  для разделения эффектов нужна регрессионная модель на большей выборке.
